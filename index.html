// 09 — Dev Notes

Things I've learned the hard way

Real lessons from building real products. No theory — just what actually happened.

DEPLOYMENT
Why Render cold starts almost killed Nigeria Pulse
Free-tier Render servers sleep after 15 minutes of inactivity. First request takes 30+ seconds. Solution: I built a self-ping cron job that hits the server every 10 minutes. Problem solved. Always design for the constraints of your hosting tier.
Nigeria Pulse · Production Issue
ARCHITECTURE
NestJS vs Express: when the structure pays off
I started with Express for everything. When Nigeria Pulse grew to 23+ scrapers and multiple AI modules, the codebase became a mess. Migrating to NestJS was painful but the module system, dependency injection, and decorators make large codebases actually manageable.
Nigeria Pulse Backend · Architecture Decision
SECURITY
I accidentally exposed my API keys twice. Here's what I learned.
Pushed .env files to GitHub. Twice. Now: .gitignore is the first file I create. Environment variables live only in deployment dashboards. I rotate keys immediately if I even suspect exposure. This lesson cost me time but not money — thankfully.
General · Hard Lesson
